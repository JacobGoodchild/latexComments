0.2.0

  • Easy maths without LaTeX: start a comment with //= (or #=, ///=, /*= */) and type the formula, for example //= L = sum_i (phi_0 + phi_1 x_i - y_i)^2.
  • Optional automatic mode (off by default) that shows comment lines which clearly are maths, and leaves code, names and notes alone.
  • Hovering over an easy-maths formula shows how it was read.

0.1.0

  • LaTeX maths in comments shown as formulas in the editor, in hover previews and in Quick Documentation.
